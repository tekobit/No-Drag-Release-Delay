# No Drag Release Delay

Disable three finger drag and drop release delay on Mac trackpads

</div>

## Modifications
Fork from [adderthorn/No-Drag-Release-Delay](https://github.com/adderthorn/No-Drag-Release-Delay)  
removed icon from menubar and fixed bag: unintended clicks firing after non-drag gestures following an initial 3-finger drag operation.

## Installation
Download and compile source code, then run the executable. Or download version from [releases](https://github.com/tekobit/No-Drag-Release-Delay/releases)  
Be sure that accessibility permissions are granted to the app. 

## Other
You can add it to run automatically on startup by adding it to Login Items in System Preferences.  
To kill the app, you can use Activity Monitor or run `killall "No drag release delay"` in Terminal.  
Works on macOS Tahoe 26.3
